# 国内外大模型分工（model-routing-guide）

面向智能体的模型选择方法：按任务性质选国内还是国外大模型。**根本目标是解决问题，而非节省成本**——模型选择以科学、合理、准确为准，经济性属次要约束。

## 有什么用处？

- 接到任务需要确定用哪一个大模型时，给出明确的分工判据
- 西方技术栈（微软系 / Adobe 系 / Apple 系 / SaaS / 海外开源）的排错、调研与学习 → **国外模型**
- 中国特色事务（国情 / 民情 / 政策 / 生活 / 微信钉钉生态 / 国内开源）→ **国内模型**

## 为什么要用？

这不是偏好，而是信息不对称的结构性原因：西方技术积累时间较长、一手资料与真实使用经验更丰富，加之技术封锁持续存在，国产模型在西方技术栈领域的训练语料在深度、广度、底层性与时效性上存在结构性差距，非模型规模或微调所能弥补；相应地，在中国特色事务领域国产模型优势明显。按领域选模型，效果通常更好。

## 如何用？

1. 接到任务先判断性质：西方技术栈还是中国特色事务
2. 选择对应模型：西方技术栈优先国外模型，中国特色事务优先国内模型
3. 经济性属次要约束，解决问题为主要目标
4. 默认选型不可用（限流、配额用尽、报错）时，及时切换次优模型，并说明"XX 不可用，已切换 YY"

## 不推荐的做法

- 用国内模型处理微软系或海外技术栈的复杂问题（存在结构性劣势）
- 仅以价格最低作为选择依据
- 用旗舰 Pro 模型处理简单问答（资源利用不充分，可提示降档）
